# MPS 초음파 진료가이드

만든이: MPS 스포츠 교육팀

## 실행

`index.html`을 브라우저에서 엽니다. `assets`, `originals` 폴더를 같은 위치에 유지하세요.

## GitHub 업로드

이 폴더 **안의 내용**을 저장소 루트에 업로드하세요.

- index.html: 시작 화면
- assets/: 화면 사진·PDF 페이지·MPS 로고
- originals/: 첨부 원본 14개와 다운로드 링크
- .nojekyll: 정적 파일 제공용

사진과 첨부 PDF 페이지는 로컬 파일로 연결됩니다. 외부 문헌·이미지 검색에는 인터넷 연결이 필요합니다.
학습 진행률과 타이머는 제거했습니다. 모든 화면 상단의 큰 ‘1단계 시작’ 버튼은 해당 부위의 첫 검사로 연결됩니다. 공통 페이지는 어깨 1단계로 연결됩니다.
기존 30단계·90개 관찰 항목·첨부 PDF 89쪽·출처는 유지했습니다.
관찰 기록은 열린 창에서만 유지되므로 필요한 내용은 텍스트로 저장하세요.

본 자료는 교육용입니다. 이미지별 출처와 사용 조건은 화면 내 확대 보기와 출처 페이지에 표시되어 있습니다.
