실행

본문, 원문 데이터, MPS 로고, 포함 사진 4개는 HTML 안에 들어 있습니다.
Pretendard 웹폰트, 외부 문헌·사진 원문, 이미지 검색에는 인터넷이 필요합니다.
오프라인에서는 시스템 한글 글꼴로 표시됩니다.

구성
- 첨부 통합 파일 순서: 어깨 → 팔꿈치 → 손·손목 → 무릎 → 고관절·골반 → 발목·발
- 6개 부위, 30개 단계, 90개 원문 확인 항목
- 검사 기본기 8개 장, 한글·영문 용어 47개, 판독 연습 8개
- 단계별 자세·탐촉자, 정상, 이상 의심, 판독 함정, 동적 평가와 기록
- 실제 초음파 사진 4개, 부위별 정상·병리 원문 링크, 각 단계 이미지 검색
- 전 부위/부위별 가이드 인쇄, 교육용 관찰 기록·텍스트 저장
- 모든 화면과 인쇄 페이지의 MPS 로고·제작팀·교육용 면책조항

원문 보존
originals 폴더의 첨부 원본 7개는 수정하지 않았습니다.
포털의 단계별 ‘첨부 원문 확인’에서도 통합 TSX와 개별 HTML 데이터를 읽을 수 있습니다.
원문의 단정적 표현, 임계값 혼용, 일부 경혈 코드 오류는 원문을 보존한 채 별도 해설했습니다.
단일 HTML만 다른 위치로 이동하면 원본 파일 다운로드 링크는 작동하지 않습니다.
화면 내 원문 데이터는 계속 사용할 수 있습니다.

세부 활용 범위와 외부 근거는 포털 ‘출처·원문·편집 해설’을 보세요.

관찰 기록
입력은 열린 페이지의 메모리 안에서만 유지됩니다. 환자 식별정보를 넣지 마세요.
새로고침·종료 시 사라지므로 필요한 기록은 ‘기록 텍스트 저장’으로 내려받으세요.
미평가는 정상으로 자동 변환되지 않습니다. 기록은 확정 진단서가 아닙니다.

인쇄
상단 ‘가이드 인쇄’는 전체 가이드를 인쇄합니다.
각 부위 목차의 ‘이 부위 전체 인쇄’로 부위별 출력이 가능합니다.
A4 인쇄 스타일입니다. 반복 로고·면책조항 출력을 위해 최신 Chrome 또는 Edge를 사용하세요.
브라우저의 기본 머리글·바닥글은 끄는 것을 권장합니다.
원문을 모두 포함해 인쇄하므로 한 단계가 여러 페이지에 걸칠 수 있습니다.
